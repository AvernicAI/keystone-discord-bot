# /memory

This folder is the project's brain, and it ships with the bot. It has two halves
that are checked against each other on every `pnpm check`:

```
memory/
  vault/       human half — open this folder in Obsidian
  machine/     machine half — the source of truth for status
  journal/     one entry per pass: what changed, what was rejected, why
  templates/   pass, RFC, spec, status, teaching, ADR, research, retrospective
  tools/       memory-check, render-memory, pass-end
```

## Open the vault

Obsidian → **Open folder as vault** → select `memory/vault`. Start at
`00-Index/Home.md`. Wikilinks work out of the box; there are no plugins to install.

## Read it as an agent

1. `memory/machine/project.json` — phase, modules, decisions, open questions.
2. `memory/machine/features.json` — the implementation status of every parity row.
3. `memory/machine/research.json` — every external claim with source, date,
   confidence and expiry.
4. `memory/machine/passes.json` — the pass ledger.
5. `memory/machine/decisions.json` — the ADR index.
6. `memory/journal/` — the reasoning, newest first. "Tried and rejected" is the
   most useful part.
7. `memory/vault/03-Architecture/` — how the system fits together.
8. `memory/vault/04-Modules/<id>/Spec.md` — what a module must do.

## The two commands

```bash
pnpm memory:render   # feature status, claims, decision index and pass ledger
pnpm memory:check    # validate machine files, generated pages and vault links
```

Generated pages carry `<!-- generated by pnpm memory:render; do not edit by hand -->`.
Edit the machine file, render, then check. A stale page fails CI.

## Rules

- **Memory that lies is worse than no memory.** A `shipped-in-repo` feature needs
  an evidence path; `verified` needs a live proof.
- **Every pass ends with a journal.** `pnpm pass:end` scaffolds it.
- **"Tried and rejected" is mandatory.** A decision without its alternatives is
  folklore, not engineering, and it teaches nobody.
- **A claim has a source, a date, a confidence and an expiry.** A claim older than
  two quarters is a rumour; refresh it or mark it stale.
- **Never paste secrets here.** The vault is public when the repo is public.
- **Never hand-edit a generated page.** `pnpm memory:check` will fail.
