# pgvector at fleet scale — research gate

**Status:** partial / open. **Date:** 2026-11-01. **Confidence:** medium for the
local exact-index result; low for production pgvector ANN at 1M×1536.

## Question

Can a 5,000-guild deployment retrieve server-doc chunks at fleet scale with
acceptable p95 latency and recall, using pgvector?

## What was measured

The repo ships `scripts/benchmark-ai.ts`, a deterministic exact-cosine harness.
It is deliberately **not** a pgvector benchmark: it measures the portable
reference index used by the module and PGlite.

```text
pnpm benchmark:ai 100000 128 20
  vectors 100000 · dimensions 128 · queries 20
  build 2510 ms · p95 scan 154.05 ms · mean 64.69 ms · recall 1.0

pnpm benchmark:ai 1000000 32 10
  vectors 1000000 · dimensions 32 · queries 10
  build 4451 ms · p95 scan 136.96 ms · mean 105.73 ms · recall 1.0
```

The 1M run meets the vector-count part of the gate, but uses 32 synthetic
dimensions (not the provider's 1536) and exact scan (not an ANN index). Recall is
1.0 by construction because the harness scans every vector; it is not evidence
of ANN recall.

## Why pgvector is not exercised here

- The test environment has PGlite, not a Postgres server with the `vector`
  extension.
- No pgvector extension package or Docker daemon is available in this workspace.
- The module stores chunk vectors portably so PGlite and a self-host without the
  extension still work. The spec does not call this pgvector.

## What would close the gate

On a Postgres instance with `pgvector`:

1. Load 1,000,000 chunks at the production embedding dimension (1536).
2. Build an HNSW or IVFFlat index with a documented parameter set.
3. Run at least 1,000 queries against ground-truth exact results; record recall@k
   and p95 latency.
4. Repeat at 5,000 guilds' realistic document volume, not only synthetic vectors.
5. Record the machine shape, index build time, memory and source/date.

Until then the P4 **Server RAG** row is implemented with a portable exact index;
the pgvector ANN row is **not** claimed as verified in marketing or Status.
