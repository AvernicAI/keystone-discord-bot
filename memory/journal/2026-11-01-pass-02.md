## What we tried and rejected

- **Build everything at once (big bang).** Rejected: no demo until month six, no
  way to learn which limits bite first, and the case model would be designed after
  four modules already depended on a worse one.
- **A plugin marketplace for third-party modules.** Rejected: unreviewed code with
  ban permissions, an unbounded support surface, and it contradicts the teaching
  goal — a marketplace teaches installation, not engineering. The module contract
  still allows out-of-tree modules; we just do not host a bazaar.
- **Premium-first, to fund development.** Rejected outright: it is the category's
  central complaint (retroactive re-gating) and violates [[Non-Negotiables]]. A
  feature that only works paid is redesigned or dropped.
- **Microservices from day one.** Rejected: gateway, worker and dashboard are
  already separate processes; splitting settings, cases and levels into services
  adds network failure modes and operator cost for no current benefit. The ports
  keep the option open.
- **AI-first roadmap.** Rejected: per-message cost, retention risk, intent
  requirements and the Shapes precedent (a bot removed from the platform wholesale).
  AI lands at P4, opt-in, capped, and unable to punish.
- **Feature count as the goal ("500 commands").** Rejected: it spends the 100-command
  budget on marketing, hurts discovery, and makes deprecation impossible. The
  matrix measures bots uninstalled, not commands shipped.
- **MEE6 parity as the definition of done.** Rejected: MEE6 has no tickets and weak
  security; parity with it would still leave an admin running three other bots.
  The bar is the union of five.
- **Writing the matrix from memory without confidence marks.** Rejected: competitor
  pricing and free-tier limits change and several sources were JS-rendered. Hence
  ❔, and hence the rule that unverified cells never reach marketing.
- **Shipping Starlight docs now.** Deferred to P7: the vault is the design record
  and the README is the front door; a docs site before the product would be a
  second thing to keep in sync.

## Critique — what the specialist round changed

- **Legal/open source** forced two rows into explicit non-goals (bundled streamer,
  translation with unclear licensing) instead of leaving them as "someday".
- **Platform engineer** cut the root-command plan from a feature-per-root instinct
  to 11 roots, with ~45 subcommands inside them, and made the budget a phase exit
  condition rather than a review comment.
- **Trust & safety** moved dry-run from "a setting" to the default posture and made
  the appeal button part of P2's exit demo, not P3 polish.
- **Data engineer** turned "export" from a P7 feature into a P5 gate, because a
  migration you cannot reverse is not a migration.
- **Ops** added the kill rule: cut scope, never extend the date.
- **Teaching lead** required a named artifact per phase, so no phase can end with
  code that has no lesson.
