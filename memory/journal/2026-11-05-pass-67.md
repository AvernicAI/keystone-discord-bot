# Pass 67 — the front door stops repeating the ledger

**Date:** 2026-11-05 · **Phase:** P7 · **Kind:** documentation and memory only

## Why

The README was 1,136 lines and AGENTS was 455. Both repeated the pass ledger,
the live evidence and the current-state counts that already live in
`memory/journal/`, `memory/vault/` and `memory/machine/`. The memory audit named
this as **A-18**: five ledgers drifting independently. A stranger had to read a
history book before learning how to run the bot, and every pass had one more
place to forget.

## What changed

- README is now a 244-line front door: pitch, exact facts, three reasons, three
  quickstarts, Discord setup, the 12-module map, the 20-root command table,
  configuration, dashboard/API, proof, memory/teaching, module contribution and
  licence.
- AGENTS is now 148 lines: the five-minute read order, all nine
  non-negotiables, the layout, the commands, live-testing rules including the
  MCP limits, and the seven-step pass protocol. It points at machine truth
  instead of maintaining a second current-state ledger.
- Every pass narrative and live-evidence transcript was removed from the
  README. The evidence still exists in the journals and the vault; no file was
  deleted.
- The gate-required facts stayed verbatim: **20/100 roots**, **141 real
  subcommands**, **161 actions**, **12 modules**, **631 tests across 92 files**,
  Docker Desktop 29.9.2, Postgres and Redis.

## Verification

- `pnpm audit:claims`: 35/35.
- `pnpm check`: green; 631 tests in 92 files, 20/100 roots, 3,746/3,746 memory
  checks.
- README 244 lines; AGENTS 148 lines.
- No command, reply, interaction, test or dependency changed.

## What we tried and rejected

- **Keep a short live-evidence section in the README.** Rejected: it becomes a
  second evidence ledger within one pass. The proof section now names the one
  live report and links it.
- **Generate the README from machine truth now.** Rejected as too large for a
  docs pass: it would need a template, a render step and a check. The README
  keeps a small facts block that `audit:claims` already verifies; a generated
  current-state block can land after the truth vocabulary pass.
- **Delete the old paragraphs outright.** Rejected because some of them are the
  only narrative record of a live run. They were already duplicated in the
  journals, so the README keeps links and the journals keep the history.
