# Pass 10 — Baseline, research and memory v2

## What changed

- Recorded the completed P0–P4 tree as the first commit (`5242b1c`) before
  changing anything, so the hotfix is reviewable as a diff.
- Added six research pages: [[Competitive-2026]], [[OSS-2026]],
  [[Platform-2026]], [[User-Voice-2026]], [[Import-Formats]] and
  [[Dashboard-Security]].
- Added machine memory: `features.json` (113 rows), `research.json` (20 claims),
  `passes.json`, `decisions.json` and updated `project.json` / `schema.json`.
- Added `memory/tools/render-memory.mjs` and `pnpm memory:render`; generated
  [[Feature-Status]], [[Claims]], [[Decision-Index]] and [[Pass-Ledger]].
- Extended `memory/tools/memory-check.mjs` to validate feature evidence, research
  sources and expiry, pass journals, decision alternatives, generated pages and
  244 vault wikilinks.
- Added ADR-0012 (intents and channel resolution), ADR-0013 (roadmap v2) and
  ADR-0014 (memory v2).
- Added the pass/ADR/spec/status/teaching/research templates.

## What we tried and rejected

- **Keep the parity matrix as prose only.** Rejected: the status page and the
  code already disagreed about open expiry jobs, and no check noticed.
- **Make `features.json` a copy of every competitor cell and delete the matrix.**
  Rejected for this pass: the competitor columns are research, not implementation
  status. The machine file is the status truth; [[Parity-Matrix]] stays the
  research table.
- **Generate the whole vault.** Rejected: teaching notes and retrospectives are
  not data; flattening them would remove the part a learner reads.
- **Use a JSON-Schema dependency for validation.** Deferred: the integrity rules
  fit in a page of dependency-free checks; add a library when the files outgrow it.
- **Rewrite the old P5–P8 docs in place and lose the history.** Rejected: the
  old labels stay readable through the migration table in [[Roadmap]] and
  ADR-0013.
